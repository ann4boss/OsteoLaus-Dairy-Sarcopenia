# Variable Definition

## Cohorts

CoLaus is a population-based cohort of adults from Lausanne, Switzerland. It has four available measurement time points: Baseline, F1, F2, and F3. Individual CSV files are provided per time point. Food frequency questionnaire (FFQ) data are available from F1 onwards. CoLaus visits are mapped to the closest OsteoLaus time point (one-to-many). CoLaus mainly contains exposure and covariate variables.

OsteoLaus is a sub-cohort of CoLaus including female participants only from age 50 to 80 years. It has five visit time points: Baseline, V2, V3, V4, and V5. OsteoLaus contains mainly outcome variables and some covariate variables.

## Merge Logic

```         
CoLaus (Baseline–F4) ──── mapped to nearest OsteoLaus wave ──── exam_date_iso (join key)
        │
        │  merge on: pt  (1:1 within wave)
        │
OsteoLaus (Baseline–V5) 
```

-   The `pt` variable is the **primary key** (participant-level unique identifier).
-   `exam_date_iso` (ISO 8601 date) is the **temporal join key**.
-   OsteoLaus → CoLaus mapping is **many-to-one**: multiple OsteoLaus visits may link to one CoLaus wave → use the most recent CoLaus wave compared to OsteoLaus visit regardless it is before or after.

## Assumptions

-   pt is unique and refers to the same participants across time points and study cohorts

-   OsteoLaus only includes female participants

-   FFQ68amount (ice cream/ sorbet) is assumed to be dairy based intake
